# 전용평대 빠른 선택과 면적 범위 연동 (2026-10-09)

## 분석과 계획

평대 버튼은 areaBands만 변경하고 minArea/maxArea는 변경하지 않아, 거래는 평대로 제한되지만 슬라이더와 입력값은 기존 범위를 표시했다. 평대 선택 이벤트에서 범위도 함께 갱신하며, 기존 여러 평대의 합집합 조회와 직접 입력한 범위의 교집합 규칙은 유지한다.

## 수정 결과

src/WeeklyPage.jsx에 공통 selectBands 처리를 두었다. 선택한 평대 중 가장 작은 시작값을 최소 면적으로, 가장 큰 평대의 끝값을 최대 면적으로 저장한다. 정확한 ㎡ 값으로 저장하고 기존 AreaRange/입력값이 이 상태를 사용하도록 했다.

- 20평대: 최소 20평, 최대 30평. 조회는 20평 이상~30평 미만이다.
- 10평대+30평대: 슬라이더 범위는 10~40평. 거래는 10~20평 및 30~40평 구간을 조회한다.
- 선택을 바꿀 때 기존에 직접 입력한 범위도 새 선택 범위로 맞춘다. 이후 직접 입력/슬라이더 조정은 선택한 평대 안에서 추가로 제한할 수 있다.
- 전체 평대, 마지막 선택 해제, 면적 필터 초기화는 평대 선택과 최소/최대 범위를 함께 제한 없음으로 되돌린다.
- 동별 화면과 즐겨찾기 대시보드에 동일하게 적용하며, 각 화면의 저장된 필터는 분리한다.

tests/weekly.test.jsx의 기존 경계/비연속 구간 검증에 입력값·슬라이더 연동, 선택 축소, 전체/마지막 선택 해제를 보강했다. tests/preferences.test.jsx의 대시보드 재접속 기대값도 새 범위로 갱신했다. 화면 설명, README와 docs/ 공개 빌드를 갱신했다.

## 후속 커밋 요청

사용자가 현재 변경 사항의 커밋을 명시적으로 요청했다. 위 미커밋 상태 기록은 요청 이전의 작업 이력이다. 탭 이름, 기타 옵션 그룹, 오른쪽 접기 버튼, 평대/면적 범위 연동과 테스트·문서·공개 빌드를 함께 커밋 대상으로 포함한다. 마지막 검증 이후 구현 코드 변경은 없으며, 비공개 local/ 진단 파일은 제외한다. 이번 요청은 커밋만 포함하므로 푸시는 수행하지 않는다.
