# 실거래 목록 표시 밀도 개선 — 2026-10-18

## 원인과 변경

모바일은 거래 한 건을 여러 줄짜리 카드로 바꿔 약 166px를 사용했다. PC는 기본 표 스타일의 셀 여백이 적용돼 행 높이가 약 53px였다. 단지별 조회에서는 큰 최근 거래 요약과 가격 흐름 안내가 거래표보다 먼저 나와 실제 거래가 첫 화면에서 밀려났다.

- 동네·단지 조회 모두 모바일에서도 행 단위 표로 표시한다. 기존 열 순서와 원본 값, 상태·해제일을 유지한다.
- 기본 셀 여백과 패널 간격을 줄였다. 숫자와 거래금액은 읽을 수 있는 크기를 유지하고 줄바꿈을 막았다.
- 390px 모바일에서는 계약일·아파트명·전용면적·층·거래금액이 처음 너비에 들어온다. 오른쪽 거래 상태·해제일은 표를 좌우로 밀어 확인하며 안내 문구를 표시한다. 320px의 더 좁은 화면에서는 거래금액도 가로 스크롤이 필요하다.
- 긴 단지명은 표 안에서 말줄임하고 전체 텍스트와 title 속성을 유지한다.
- 최근 유효 거래 요약과 면적별 가격 흐름을 거래표·페이지 이동 아래로 옮겼다. 최근 거래 요약도 기본적으로 접혀 있으며 필요할 때 연다.
- 선택된 거래 화면의 자료 안내·탭·필터 도구 모음과 결과 패널 간격을 줄였다. 거래를 선택하기 전 검색 화면과 지도·대시보드는 이 상단 압축의 대상에서 제외했다.
- 페이지당 자료 수(모바일 20건, PC 50건)와 자료 로딩 범위는 그대로다. 행 배치와 여백을 바꿔 같은 자료를 더 많이 보이게 했다.

표 관련 스타일은 `src/transactions/transaction-density.css`에 모았다.

## 같은 조건의 실제 브라우저 비교

풍덕천동 2026년 9월 거래를 같은 뷰포트, 기본 확대율, 페이지 맨 위에서 비교했다. 화면 안에 온전히 들어오는 행만 세었고 모바일 하단 고정 메뉴가 가리는 행은 제외했다.

| 화면 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 모바일 390×844 첫 화면의 동별 거래 | 2건 | 13건 |
| PC 1440×900 첫 화면의 동별 거래 | 7건 | 19건 |
| 모바일 행 높이 | 165.75px | 28px |
| PC 행 높이 | 53.16px | 29px |

단지 조회의 별도 표본인 ‘동부’는 해당 기간 자료가 총 7건이었다. 모바일 첫 화면의 표시 행은 0→7건, PC는 2→7건으로 늘었다. 표본 수를 넘는 일반적인 표시 용량을 뜻하지는 않는다.
