# 동 별 실거래가 옵션 그룹 변경 (2026-10-09)

## 분석과 계획

조회 화면은 주간·월간·직접 지정 조회를 지원하지만 탭 이름은 동별 주간 실거래가였다. 해제 거래 포함은 1·2번 카드와 3번 지역 카드 사이에 별도 줄로 표시됐으며 카드 내용을 접을 수 없었다.

탭/페이지 제목을 동 별 실거래가로 바꾸고, 기존 조회 기간과 URL/저장 설정은 유지한다. 해제 거래 포함은 3번 아래의 4번 기타 옵션으로 옮긴다. 1~4번 그룹의 공통 접기/펼치기 UI를 분리하며, 숨기는 동안 입력 내용과 조회 결과를 유지한다.

## 구현 결과

- src/App.jsx: 탭 제목을 동 별 실거래가로 변경.
- src/weekly/FilterGroup.jsx: 독립된 접기 상태, 제목 버튼, aria-expanded/aria-controls, 고유 콘텐츠 ID. 기본은 펼침이며 제목 버튼은 마우스/키보드로 사용할 수 있다. 콘텐츠는 hidden으로 숨기며 제거하지 않는다.
- src/PeriodPicker.jsx: 1번 조회 기간 그룹 적용.
- src/WeeklyPage.jsx: 2번 전용면적, 3번 조회할 동, 4번 기타 옵션 그룹 적용. 해제 거래 포함과 신고 지연 안내를 4번으로 이동. 제목과 빈 조회 안내도 기간 조회에 맞췄다.
- 즐겨찾기 대시보드도 공통 그룹을 사용하므로 3번은 즐겨찾기 아파트 목록으로 표시된다. 이전에 제거한 거래표 별표 안내를 현재 즐겨찾기 방식으로 정정했다.
- src/dong-filters.css: 펼침 상태 화살표, 포커스 테두리, 접힌 카드 간격, 모바일 배치. 접힌 카드가 옆의 열린 카드 높이로 늘어나지 않도록 조정했다.
- tests/weekly.test.jsx: 독립 접기, 입력/결과/해제 설정 유지, 키보드 재펼침 회귀 검증. 관련 테스트의 탭 이름 기대값도 갱신했다.
- README.md 및 docs/: 현재 사용법과 공개 빌드 갱신.

접기 상태는 화면이 표시되는 동안 유지하며 탭을 다시 열면 기본 펼침으로 시작한다. 기존 기간·면적·동·해제 설정 저장 방식과 거래 원문은 바꾸지 않았다.

## 검증과 요약

React 테스트 62개, pnpm build, pnpm check:publish(169개 파일), git diff --check 통과. 실제 브라우저에서 01→02→03→04 순서, 3번 뒤 기타 옵션 배치, 독립 접기/펼침, 최대 면적 85㎡와 월 2026-09 보존, 해제 설정 보존, 조회 결과 유지, Enter 키 동작을 확인했다. 390px 모바일 문서 폭은 390px이며 접힌 각 그룹 높이는 70px이었다. 대시보드의 그룹/기타 옵션도 확인했고 pageerror는 0개다.

## 후속 요청: 접기·펼치기 버튼을 맨 오른쪽으로 이동

제목에 합쳐져 있던 접기 버튼을 독립된 40×40px 버튼으로 분리하여 헤더의 마지막 요소로 배치했다. 제목·번호·기간 기준·면적 단위·선택 해제/즐겨찾기 추가 버튼은 왼쪽 헤더 영역에 둔다. 좁은 화면에서는 왼쪽 영역만 줄을 나눠 버튼이 항상 맨 오른쪽에 남는다. 기존 접근성 이름과 aria-expanded/aria-controls, 키보드 동작, 접기 상태 및 입력값 보존은 유지한다. README 사용법도 오른쪽 버튼 기준으로 갱신했다.

검증: 관련 React 테스트 24개, pnpm build, 공개 파일 검사(170개), git diff --check 통과. 실제 데스크톱과 모바일 390px의 모든 그룹에서 버튼 오른쪽과 헤더 오른쪽 사이 간격이 0px이며, 다른 버튼이 접기 버튼 오른쪽으로 넘어오지 않았다. 대시보드 및 320px 화면에서도 같은 배치와 문서 폭을 확인했다. 390px에서 접힌 그룹 높이는 74px이며 pageerror는 0개였다. 접기/재펼침, 기간·면적·해제 설정, 조회 결과 보존도 확인했다.

로그와 화면은 local/weekly-groups-right-browser-result.json 및 local/weekly-groups-right-*.png에 저장했다. 커밋·푸시는 하지 않았다.

## 후속 커밋 요청

사용자가 현재 변경 사항의 커밋을 명시적으로 요청했다. 위 미커밋 상태 기록은 요청 이전의 작업 이력이다. 탭 이름, 기타 옵션 그룹, 오른쪽 접기 버튼, 평대/면적 범위 연동과 테스트·문서·공개 빌드를 함께 커밋 대상으로 포함한다. 마지막 검증 이후 구현 코드 변경은 없으며, 비공개 local/ 진단 파일은 제외한다. 이번 요청은 커밋만 포함하므로 푸시는 수행하지 않는다.
