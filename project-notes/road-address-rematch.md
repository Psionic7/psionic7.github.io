- [x] 같은 정규화 함수를 실거래·공통 식별 정보·네이버 주소 검증에 적용한다.

기존 작업 DB와 매물 스냅샷을 백업한다. 커밋·푸시는 수행하지 않는다. 단지별 예외를 코드에 추가하거나 준공연도 충돌을 묵인하여 성공 건수를 늘리지 않는다.

## 확인한 문제와 수정

도로명주소 공백과 끝 괄호 참고항목, 산 지번 공백이 서로 달랐다. 공통 정규화 후 검증 주소와 별칭으로 후보를 조회한다. 같은 주소가 여러 표기로 저장돼도 주소 충돌로 처리하지 않는다.

기존 연결 실거래에서 생긴 별칭을 모두 새 이름 근거로 사용하면 오류를 반복할 수 있다. 독립적으로 검증한 별칭과 기존 연결 별칭을 구분했다. 기존 연결은 도로명주소·주지번·준공연도가 일치할 때만 유지한다. 단지 차수 충돌은 보류한다.

브라우저 검색은 이전 입력과 최근 검색 목록을 자동완성으로 오인했다. 문서 준비와 입력 완료를 확인하고 `.type_recent` 항목을 제외한다. 후보 순서가 바뀌어도 현재 화면의 정확한 이름을 다시 찾아 선택한다. 실제 Chrome 테스트에서 이전 입력, 최근 검색, 후보 순서 변경, 이웃 지번 거부, 매매 전체 페이지 수집을 확인했다.

수집 실패 후 과거 공개 스냅샷이 더 최신 DB 관찰을 덮어쓰던 경로도 수정했다. 이전 광고는 수집 시각을 유지해 보존한다.

서버가 단지정보를 HTML로 렌더링할 때는 화면의 지번만 저장하고 도로명주소를 버리고 있었다. 단지정보 표의 도로명 표시를 함께 저장하도록 수정했다. API 관찰이 있으면 같은 지번 주소임을 확인한 뒤 화면의 도로명주소를 보완한다. 같은 검색의 후보 결과는 한 실행 안에서 재사용하고 각 대장 ID의 주소를 별도로 검증한다.

실제 미확정 사례로 수내동 53의 파크타운을 추적했다. 네이버 검색 후보 3084의 화면 주소는 수내동 51·내정로 186이고 대장 대상은 내정로174번길 42였다. 이 경우는 공백 정규화로 해결할 수 없다.

후보의 주소를 먼저 검사한 뒤 검증된 단지 하나의 매매 전체 페이지를 수집한다. 주소가 다르거나 검증된 후보가 여러 개면 전체 매물 수집 전에 보류한다. 주소 사전 검사와 후보 검색 결과는 실행 중 재사용하며, 전체 매물의 최종 주소·페이지 검증은 그대로 수행한다.

백현마을8단지 사례는 일반 이름 검색으로 2·5·6·7단지까지 탐색하다 제한 시간을 넘었다. 등록된 단지 차수가 하나로 확인되면 구체적인 별칭으로 검색하고 다른 명시적 차수는 검색·후보·최종 주소 검증에서 제외한다. 대표 이름과 연결된 실거래 이름의 차수를 먼저 확인해 수집 과정에서 얻은 다른 차수 별칭이 기준을 바꾸지 않도록 했다. 차수가 상충하거나 `4-1단지` 같은 복합 표기면 단일 차수를 강제하지 않는다. 차수가 없는 네이버 이름은 주소 검증 대상으로 유지한다. 백현마을8단지는 수정 후에도 주소가 맞는 후보를 확인하지 못해 검색 미확정으로 기록했다. 이는 매물 0건을 확인했다는 뜻이 아니다.

미확정 대상 검사에서 분당테크노파크 4개 대장의 실제 용도가 `아파트형공장`임을 확인했다. `아파트`라는 부분 문자열로 주거 아파트로 분류하던 규칙을 수정했다. 공식 재구성 명령은 저장된 층별 원천 자료가 있는 범위의 분류를 다시 계산한다. 원천 층별 자료가 없는 이전 캐시는 유지하며, 공장과 실제 주거층이 혼합된 건물의 주거 분류도 보존한다. 광교아르데코는 실제 주거층을 확인해 복원했다. 수집 대상은 467개에서 공장 4개를 제외하고 주거 단지 1개를 추가한 464개다. 원본 대장·실거래 행과 기존 ID는 삭제하지 않는다.

## 검증 결과

Node 테스트 201개, 데이터 테스트 23개, 화면 테스트 143개, 실제 Chrome 통합 테스트 1개가 통과했다. 데이터 테스트는 Node 테스트에도 포함된다. Chrome 테스트는 이전 입력·최근 검색 제외, 후보 순서 변경, 다른 차수 거부, 화면 도로명주소 보존, 다른 건물 번호 거부, 매매 전체 페이지와 전세 제외, 보안 확인 시 중단을 확인한다.

`pnpm data:verify`와 빌드 전후 검사에서 실거래 344,494건의 원본·추출 일치를 확인했다. `pnpm check:publish`는 공개 파일 362개를 검증했다. 기존 연결 374개는 연결 ID 변경이나 새 보류 없이 유지됐고 2개 연결을 추가했다. `git diff --check`도 통과했다.

```powershell
pnpm test:node
pnpm test:data
pnpm test
node --test tests/naver-nodriver.integration.mjs
pnpm data:verify
pnpm build
pnpm check:publish
```

Chrome 테스트에는 `NAVER_BROWSER_PYTHON`을 nodriver가 설치된 Python으로 설정했다. 로컬 미리보기 `http://127.0.0.1:5173/?tab=apartments`를 브라우저 패널에 열어 광교아르데코의 실거래 3건과 매매 매물 34건을 확인했다. 커밋·푸시는 수행하지 않았다.
