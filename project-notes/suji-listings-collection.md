# 수지 매물 수집과 반영 — 2026-11-07

후속 매매 전용 변경으로 현재 공개 자료는 아래 전체 거래 809건 중 매매 681건만 유지한다. 원래 관찰 시각과 일부·전체 구분은 유지했으며 새 수집으로 기록하지 않았다. 예약 실행과 현재 범위는 [매매 일일 수집 기록](sale-listings-schedule.md)을 확인한다.

## 요청과 범위

수지 지역의 실제 네이버 부동산 매물을 수집하고 검증한 뒤 커밋·푸시한다.
기본 수집 설정의 풍덕천동·동천동·신봉동·성복동·상현동에 등록된 대상 199개를 기준으로 한다.
등록 대상에는 같은 네이버 단지에 연결되는 건축물 대장 항목이 포함되므로 실제 단지 수와 구분한다.

## 계획과 실행

1. 원격 main과 작업 트리, 수집 대상 목록을 확인한다.
2. 네이버 화면에서 단지를 검색하고 등록 단지명과 대조한다.
3. 시스템 Chrome이 화면 탐색 중 받은 공개 매물 응답을 읽고 지번 주소를 다시 검증한다.
4. 광고 번호·거래 유형·가격·보증금·월세·목록 면적·동·층·확인일·중개사·설명을 정규화한다.
5. 전체 페이지 확인 여부를 보존하고 기존 성공 자료를 유지하며 결과와 보고서를 저장한다.
6. 데이터·화면·빌드·공개 파일 검사를 마친 뒤 요청한 커밋과 푸시를 수행한다.

## 도구와 재실행

- insane-search에서 확인한 nodriver 기반 시스템 Chrome 실행 환경을 사용한다.
- `scripts/naver-system-chrome.py`는 탐색으로 발생한 응답만 읽는다. 요청 헤더·인증 값·사용자 브라우저 프로필을 수집하거나 내보내지 않는다.
- 기본 전체 수집 모드는 연속 페이지와 마지막 페이지를 확인하지 못하면 실패한다. 이번 실행은 명시적인 `--partial`로 첫 목록을 보존했다.
- 현재 네이버 응답의 주소 필드 `address`와 기존 `cortarAddress`를 지원한다. 초기 단지 정보가 HTML에 렌더링된 경우에는 화면의 주소 표를 대조한다.
- Windows 자식 Python은 UTF-8로 실행한다. 일시적 파일 잠금은 제한된 횟수만 재시도한다.

```powershell
python -m venv .venv-naver
.\.venv-naver\Scripts\python.exe -m pip install -r scripts/requirements-naver-browser.txt
pnpm listings:region --region-code 41465 --connections local/suji-connections.json --python .venv-naver/Scripts/python.exe --partial --resume
```

별도의 Python 환경과 시스템 Chrome이 필요하다. 이번 실행은 전용 Python 3.12 환경을 사용했다.
연결 파일은 `[{"id":"등록 대상 favorite.id","complexNo":"네이버 단지 번호"}]` 배열이다.
모호하거나 단지명이 다른 결과를 연결 파일에 넣지 않는다. 번호를 지정해도 실제 지번 검증을 통과해야 저장된다.
`--resume`은 같은 단지 번호로 저장된 24시간 이내 성공 관찰을 재사용하며 수집 시각을 새로 만들지 않는다.
이 명령은 일일 전체 수집 완료를 기록하지 않는다. 기존 예약 수집기는 전체 페이지 검증을 계속 요구한다.

## 산출물과 검증

- `public/listings/snapshot.json`: 정규화한 실제 광고와 일부·전체 수집 구분. 기존 분당 자료도 유지한다.
- `public/listings/region-41465-report.json`: 등록 대상별 수집 결과와 중복 제거 집계.
- `naver-listings-preview.html?region=41465`: 지역과 단지명으로 조회하는 결과 화면. 빌드 결과에도 포함한다.
- 원본 응답과 단지 연결 검색 기록은 Git에서 제외한 `local/`에 보관한다.

단지 연결 저장은 자동 승인 검토에서 명백한 오연결 때문에 한 차례 거절됐다.
해당 후보들을 제외하고 단지명 대조를 통과한 55개 후보만 저장한 뒤, 실제 수집에서 지번을 다시 확인했다.
오연결 후보를 승인 없이 우회 저장하지 않았다.

수집 중 중단된 진단용 일일 실행은 미완료 상태로 마감했다. 일부 수집을 예약 수집 성공으로 바꾸지 않았다.
실거래 원본 DB는 재수집하거나 변경하지 않았다.
