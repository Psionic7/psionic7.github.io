## 운영 적용 전 필요한 수정

1. 상세 실거래 API 접근 권한과 실제 공식 단지번호 필드를 확인한다. 원문·거래 행 ID와 별도로 공급자 종류·단지번호를 보존하고 로컬 승인 연결을 만든다.
2. 아파트·공급자 연결 기준본을 버전과 해시로 전달한다. GitHub가 복원한 수집 DB의 옛 아파트 정보를 기준으로 사용하지 못하도록 강제한다.
3. 운영 수집기를 확정 연결 전용으로 바꾼다. 현재 `collectDailyListings`는 미확정 대상을 자동 탐색하고 아파트 정보를 동기화하는 경로가 남아 있다. 이번 검증은 그 경로를 호출하지 않았다.
4. 수집 관측 오류와 로컬 연결 승인을 분리한다. 현재 운영 코드에는 `address_mismatch` 발생 시 연결과 아파트의 네이버 번호를 지우는 경로가 있다. 검토 상태·관측 이력을 남기면서 로컬 승인 연결은 보존해야 한다. 이번 `site_unavailable`에서는 이 삭제 경로가 실행되지 않았다.
5. 네이버 정상 접근을 확인한 뒤 확정 연결 388개의 수집을 다시 검증한다. 미확정 81개와 위 실거래 5개 원천은 로컬 확인 작업으로 분리한다.

공식 단지번호 스키마 이관과 운영 수집기 변경은 이번 실행에서 구현하지 않았다. 기본 API 수집 성공만으로 위 운영 기준을 충족한다고 보고하지 않는다.
