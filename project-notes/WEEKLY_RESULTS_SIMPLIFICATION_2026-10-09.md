# 동별 결과를 실거래 목록으로 간소화

동별 결과에서 유효 거래, 최저 거래금액, 최고 거래금액, 거래된 아파트 카드 4개와 바로 아래 통계 설명 줄을 제거했다. 제목과 지역/기간 뒤에 실거래 표와 페이지 이동을 바로 표시한다.

src/weekly/WeeklyResults.jsx에서 통계 카드/계산은 즐겨찾기 아파트 대시보드에만 적용하도록 제한했다. 동별 기간·면적·평대·해제 필터, 원래 신고 금액, 거래 상태·해제일, 50건 페이지 이동과 22px 행 높이는 유지했다. README와 기존 주간 테스트도 동별 목록 기준으로 갱신했다.

검증: React 테스트 62개, 공개 빌드, 공개 파일 검사(170개), git diff --check 통과. 실제 브라우저에서 동별 카드 4개와 설명 줄 없음, 6개 컬럼, 47개 거래, 면적 조건 변경 후 44개 거래를 확인했다. 모바일 390px 문서 폭과 22px 행 높이를 유지했으며 pageerror는 0개였다. 기존 대시보드 통계 테스트도 통과했다.

증거는 비공개 local/weekly-trades-only-browser-result.json, local/weekly-trades-only-desktop.png, local/weekly-trades-only-mobile.png에 저장했다. 커밋·푸시는 하지 않았다.

## 후속 커밋·푸시 요청 (2026-10-10)

사용자가 현재 변경 사항의 커밋과 푸시를 명시적으로 요청했다. 위 미커밋 기록은 요청 이전의 작업 이력이다. 동별 요약 제거, 기존 테스트 갱신, 문서와 공개 빌드를 커밋 대상으로 포함한다. 앞서 로컬에만 커밋한 필터 개선 30a8c75와 함께 main 브랜치로 푸시한다. 마지막 검증 이후 구현 코드 변경은 없으며 비공개 local/ 진단 파일은 제외한다.
