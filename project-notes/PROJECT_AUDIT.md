# 기존 프로젝트 분석 및 React 이전 기록

분석일: 2026-10-03. 대상: 관리자 PC의 `my_real_estate` 및 비공개 `Psionic7/my-real-estate` 저장소. 이 문서는 이전 시점의 구조·규칙·위험·유지 항목을 기록합니다. API 인증 값은 기록하지 않습니다.

### 이전 후 변경: 즐겨찾기 기반 조회 (2026-10-03)

공개 화면에서 수지·광교·분당 고정 바로가기와 자동 초기 선택을 제거했습니다. 로컬 지도에서 별표로 선택하고 업데이트한 지역을 공개 manifest v2의 `favorite_region_ids`로 내보내며, 즐겨찾기 바로가기와 지역 비교 모두 이 목록을 사용합니다. 원본 수집 목록 파일이나 저장 시각·관리 메타데이터는 공개하지 않습니다. 파일이 없거나 저장 목록이 비어 있으면 즐겨찾기는 빈 배열입니다. 초기 조회는 미선택이며 공유 URL의 명시적인 유효 지역만 복원합니다. 전체 시·구·동 검색과 거래 데이터는 유지합니다. 아래 기본 3개 지역 설명은 최초 이전 당시 구조의 기록입니다.

## 1. 실행·구성·배포

기존 앱은 Python 3.12, Streamlit 1.64.0, pandas 3.0.6, Altair 6.3.0, defusedxml 0.7.1, python-dotenv 1.2.4를 사용합니다. requirements에는 pydeck도 있지만 수집 지도는 Leaflet 커스텀 컴포넌트입니다. `app.py`가 화면 진입점이고 `run.bat` → `scripts/run_local.py`가 로컬 모드를 켜고 127.0.0.1의 8503–8513 중 사용 가능한 포트에 바인딩합니다.

기존 Git 저장소는 Private, Streamlit 조회 앱은 Public입니다. 작업 DB와 수집 지역 목록은 비공개 저장소에서 관리되고 API 키는 이 저장소에서도 제외됩니다. React 사이트는 새 Public 저장소에 별도 Git 이력으로 생성합니다. 기존 앱·배포를 삭제하지 않고 공개 조회의 운영 주소를 GitHub Pages로 전환합니다.

## 2. SQLite 모델

### 공개 가능한 테이블

- **trades**: `id`, `region_code`, `deal_month`, `deal_date`, `apartment`, `dong`, `jibun`, `price_man`, `area_m2`, `floor`, `build_year`, `cancelled`, `raw_json`. `(region_code, deal_month)` 인덱스. `raw_json`에 API의 모든 필드를 문자열 그대로 보존하고 정규화 값은 별도 열로 관리합니다.
- **regions**: `region_id`, 고유 `label`, `region_code`, `region_name`, `dongs_json`, `latitude`, `longitude`. 지역은 API 수집 단위와 조회 범위를 연결합니다.
- **metadata**: 키/값. 공개 DB에는 공개 시각만 옮깁니다.

### 로컬 전용 테이블과 파일

- **collection_runs**: 지역·월·수집 시각·API 건수·저장 건수.
- **api_pages**: 각 수집 실행/페이지의 응답 XML. API key 문자열은 원문에서도 제거하도록 처리합니다.
- **data/collection_regions.json**: 버전, 저장 시각, 선택된 수집 지역 정보. 공개 조회에 필요하지 않은 관리자 설정입니다.
- **.env**: MOLIT_SERVICE_KEY. Git 및 공개 DB·JSON·빌드에서 제외합니다.

기존 공개 생성기는 읽기 트랜잭션으로 일관된 데이터만 새 DB에 복사하고 무결성, 실제 키 포함 여부, 95 MB 제한을 검사한 뒤 원자적으로 교체합니다. 새 내보내기도 허용 열·테이블을 명시하여 DB를 재구성합니다. 작업 DB 파일을 복사하거나 테이블을 삭제하는 방식으로 공개하지 않습니다.

## 3. 수집 동작

endpoint는 MOLIT `RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade`. `LAWD_CD`는 법정동 코드 앞 5자리, `DEAL_YMD`는 YYYYMM입니다. 한 페이지 1,000건, HTTP timeout 30초, 429/5xx/연결 실패에 최대 3회 재시도합니다. defusedxml로 응답을 파싱하고 resultCode·totalCount·페이지별 건수를 확인합니다. 페이지 도중 전체 건수가 달라지거나 누락된 페이지가 있으면 저장하지 않습니다.

정규화는 날짜의 실제 존재·요청 계약월 일치, 시군구 일치, 양수 금액, 0 초과 10,000㎡ 미만 면적, 아파트명·법정동을 검증합니다. 거래 금액의 쉼표는 계산용 숫자에서만 제거하고 raw에서는 남깁니다. 층·건축년도는 비어 있으면 null입니다. `cdealType`이 O/Y/1이거나 해제일자가 있으면 해제 거래입니다.

지역·월의 모든 페이지를 검증한 다음 한 트랜잭션에서 기존 월을 DELETE하고 새 응답을 INSERT합니다. 실패한 월의 기존 자료는 유지됩니다. 서로 구별할 수 없는 동일 신고도 임의로 제거하지 않습니다. 같은 시군구의 여러 동을 선택해도 시군구·월 요청은 한 번만 수행하고 API 응답 전체를 보존합니다.

월 범위는 유효 YYYYMM, 시작 ≤ 종료, 미래월 제외, 최대 360개월입니다. **기존 CLI에서 `--region`을 생략하면 등록한 전체 지역을 수집**합니다. 지도에 저장한 선택만 수집하는 UI와 다르므로 관리자는 UI 또는 명시적 `--region`으로 수집 범위를 지정해야 합니다. 이번 이전에서 API 수집은 자동 실행하지 않았습니다.

## 4. 지역·지도·선택 관리

기본 관심 지역은 수지구 전체, 분당구 전체, 광교(영통구의 이의동·하동·원천동)입니다. 법정동 8자리 코드의 앞 5자리와 API 시군구 코드를 연결합니다. 법정동과 행정동은 다른 기준입니다.

경계는 V-World 원자료를 WGS84로 변환한 kr-admin-geojson의 2023-07-29 자료로, 서울 467 / 경기 745 법정읍면동입니다. 67개 시군구 API 단위(서울25/경기42), 32개 시 단위(서울+경기31), 구 단위 경계를 준비했습니다. 좌표는 EPSG:4326의 경도·위도 순서, 단순화 오차 약 0.0005도, 소수점 6자리입니다. 2024 부천·2026 화성 등의 개편은 목록과 경계에 반영되지 않았습니다. 새 코드가 필요한 경우 로컬 지역 설정으로 추가할 수 있지만 최신 경계를 자동 생성하지는 않습니다.

지도는 인증키 없는 OSM 표준 타일, Leaflet 1.9.4, jsDelivr 모듈·스타일을 사용합니다. 시는 굵은 실선, 구는 점선, 동은 가는 실선이며 시/구별로 색을 다르게 표시합니다. 선택 대상은 금색 테두리와 진한 채움입니다. 확대 수준에 따라 시/구/동 이름을 표시합니다.

폴리곤 클릭은 정보 팝업을 열고, 팝업 오른쪽 위 별표만 수집 대상을 변경합니다. 기존 문제 수정 후 Leaflet map·타일·레이어·열린 팝업을 유지하며 변경된 동 레이어와 별표 상태만 갱신합니다. Streamlit 재실행 때 오래된 모듈을 재로딩하는 버전 검사도 적용돼 있습니다.

별표, 다중 선택, 구/시/필터 전체 추가·해제는 **세션 메모리 초안**만 변경합니다. 저장 목록과 다르면 노란 `업데이트 필요`와 추가/해제 건수를 표시합니다. `수집 지역 업데이트`에서만 검증·fsync·임시 파일·원자적 교체를 수행하고 `변경사항 되돌리기`는 저장된 파일을 복원합니다. API 수집은 메모리 초안이 아닌 **저장된 목록**만 사용합니다. 빈 선택도 명시적으로 저장할 수 있고 손상 파일은 조용히 덮어쓰지 않습니다.

이 관리자 지도·선택 동작은 기존 로컬 프로젝트에 그대로 유지합니다. React 공개 화면은 지역 목록 조회만 제공합니다.

## 5. 기존 조회·통계 규칙

조회는 지역 코드·기간·선택한 법정동으로 SQL 필터링하고 계약일 DESC/id DESC 순서로 읽습니다. 공개 모드와 로컬 모드는 다른 DB를 사용합니다. Streamlit 데이터 캐시는 파일 수정 시각/크기/지역 조건을 키로 하고 ttl300·최대40개입니다. 열린 탭만 계산하는 상태ful 탭을 사용합니다.

대시보드 규칙:

1. 해제 거래 제외, 최소/최대 면적 포함, 선택 법정동 필터.
2. 거래금액 억 원 = `price_man / 10000`.
3. 전용평당 만 원 = `price_man / (area_m2 / 3.305785)`.
4. 가격과 전용평당 가격은 중앙값. 단지 수/집계는 `(dong, jibun, apartment)` 조합.
5. 월별 전체 연속 기간을 표시하며 미거래월 건수0, 가격 null. 데이터가 없는 달의 가격을0으로 만들지 않음.
6. 분포 차트는 최대3,000건. 기존 Python은 random seed7 샘플; React는 계약일 순서를 고르게 추린 결정적 샘플. 통계는 양쪽 모두 전체 자료로 계산.
7. 면적 구간 `(0,60]`, `(60,85]`, `(85,102]`, `(102,135]`, `(135,∞)`.
8. 관심 지역 비교는 같은 기간·면적 기준이며 화면의 상세 법정동 필터를 비교 지역에 적용하지 않음.
9. 단지 표는 거래 건수 DESC/금액 중앙값 DESC 상위30. 동률 정렬은 표시용 기준이며 수치는 같음.

원천 표는 API 필드를 문자열로 유지합니다. 알려진20개 필드를 먼저 표시하고 새 필드도 빠뜨리지 않습니다. 모든 열에 포함·일치·제외·빈 값·숫자 이상/이하 필터를 AND로 조합합니다. 숫자 필터는 쉼표를 제거해 비교하지만 빈 값은 숫자로 취급하지 않습니다. CSV는 UTF-8 BOM, 원천 값·줄바꿈·쉼표·따옴표·빈 값을 보존하고 필터 전체 결과를 내려줍니다. 100/500/1,000행 페이지를 지원합니다.

## 6. 로컬 접근 통제와 공개 경계

기존 관리자 UI는 `MY_REAL_ESTATE_LOCAL=1`, 클라우드 실행 표식 없음, 서버 주소 루프백, 접속 IP 루프백을 검사합니다. 관리자 비밀번호 인증은 없으며 네트워크에 공개하지 않는 로컬 실행을 전제로 합니다. 파일·DB 쓰기마다 require_local을 다시 검사합니다. 새 데이터 내보내기 버튼도 같은 접근 검사를 사용합니다.

공개 React에는 수집 endpoint·인증 값·쓰기 서버·관리자 설정 파일이 없습니다. 서버가 없는 Pages에서 관리자 API 수집을 실행할 수 있게 바꾸지 않았습니다. React/JSON/SQLite 다운로드는 모두 Public이므로 공개할 수 있는 거래·조회 지역 정보만 포함합니다. 원문 XML·수집 이력·키·수집 대상 초안과 파일은 제외합니다.

## 7. React 이전 구현

- React19.3 / Vite8.3 / Recharts3.10 기반 SPA. `src/domain.mjs`는 UI와 분리된 통계·필터 함수입니다.
- `App.jsx`는 목록·지역 계층·계약월·공유 URL·로딩/오류/빈 상태·탭을 관리합니다.
- `Dashboard.jsx`는 지표·Recharts 차트·비교·집계 표. 지연 로딩으로 첫 JS 부담을 줄입니다.
- `RawTable.jsx`는 열별 필터·정렬·열 숨기기·페이지·전체 결과 CSV·필드 안내.
- `data.js`는 API 시군구 단위 정적 JSON을 필요할 때 읽고 같은 파일 요청을 재사용합니다. 이전 지역의 느린 응답으로 현재 선택을 덮어쓰지 않습니다.
- `scripts/export_data.py`는 stdlib-only 내보내기, allowlist SQLite 재생성, raw 문자열 검증, 실제 키 검사, 내용 해시 파일명, manifest 마지막 원자 교체.
- `scripts/check_public.py`는 비공개 파일·키·예상 외 데이터 파일·DB 테이블·무결성·JSON 체크섬·건수·빌드 최신 여부 검사.
- 공개 SQLite는 다운로드용이며 브라우저가 DB 전체를 매번 받아 실행하지 않습니다. 시군구 JSON을 조회용으로 분할합니다.
- `docs/` 빌드 결과를 커밋하고 GitHub Pages에서 main/docs로 배포합니다. 서버 런타임·Cloud secrets·유료 요금제가 필요하지 않습니다.
- Python 수집 도구와 저장한 선택 목록은 비공개 원래 프로젝트에 남습니다. 사용자 작업 DB/지역 목록의 기존 변경을 초기화하지 않습니다.

## 8. 검증 항목 및 한계

독립 Node 테스트로 해제/지역/면적 경계·단지 식별·중앙값·월별 공백·일곱 필터·CSV 보존을 검사합니다. React DOM 테스트로 열 필터·페이지 초기화·CSV 전체 결과·미수집 동·이전 비동기 응답 무시·수집 기능 부재를 검사합니다. Python 내보내기 테스트로 비공개 테이블/키 제외, 실패 시 기존 데이터 유지, 빈 DB를 검사합니다. 기존 Python 분석과 현재 정적 JSON의 지표·월별·단지·원천 필터 결과도 비교합니다. 로컬 접근 통제와 기존 관리자 테스트를 재실행합니다.

GitHub Pages 배포 후 익명 HTTPS 응답·빌드 자산·manifest·시군구 JSON·SQLite 경로와 체크섬을 확인합니다. DOM 자동 테스트와 정적 배포 검증은 실제 Chrome에서의 시각적 검사와 다릅니다. 화면 디자인은 사용자의 브라우저에서 추가 피드백을 받을 수 있습니다.

현재 경계 목록의 과거 기준일, 미수집 지역, 정적 데이터의 배포 지연은 이전으로 해결되지 않습니다. 더 많은 시군구/연도를 수집해 데이터가 커지면 JSON을 월 단위로 더 분할하고 공개 SQLite가95MB를 넘기 전에 제공 범위를 조정해야 합니다. API key는 로컬 `.env`에서 관리하며 Public 저장소에 저장하지 않습니다.
