# 지역 지도 동 경계 구분 개선

## 분석

공개 지역 지도의 일반 동 경계는 0.75px, 채움 불투명도 0.1이며 같은 시군구의 동은 같은 색을 사용한다. 배경 지도 도로·공원과 선·색이 섞여 인접 동 구분이 약하다. 관리자와 지도 컴포넌트를 공유하지만 공개 지역 지도는 favoriteMode로 구분된다.

## 계획

1. 공개 지역 지도에서는 동 경계를 진한 1.6px 실선으로 표시하고, 법정동 코드에 따른 고정된 파스텔 색과 더 선명한 채움을 사용한다.
2. 배경 지도는 약하게 표시하고 즐겨찾기는 금색 채움과 굵은 금색 경계로 구분한다. 시·군 실선 및 구 점선은 유지한다.
3. 범례를 실제 표시에 맞추고 지도 위치·팝업·별표 저장과 모바일 화면을 검증한다. 관리자 기본 스타일은 유지한다.

## 수정 결과

- 공개 지역 지도에서 일반 동 경계를 진한 회색 1.6px 실선으로 변경했다. 기존 0.75px보다 두껍고 불투명하게 표시한다.
- 법정동 코드에 따라 6가지 파스텔 색을 고정 배정하고 일반 동의 채움 불투명도를 0.1에서 0.23으로 높였다. 검색/새로고침/즐겨찾기 변경에도 일반 동의 색이 유지된다.
- 배경 타일 불투명도를 0.72로 낮춰 도로·공원보다 동 경계가 더 눈에 띄도록 했다.
- 즐겨찾기 동은 금색 채움과 3.2px 금색 경계로 강조한다. 별표 해제 시 해당 동의 고정 색으로 돌아간다.
- 시·군 굵은 실선 및 구 점선은 유지하고 공개 지도 범례를 실제 표시와 맞췄다. 관리자 지도는 기존 기본 스타일을 사용한다.
- 지도 경계 자료와 좌표, 클릭 및 별표 저장 처리 자체는 유지했다.

## 검증 결과

- React 테스트 13개 파일, 78개 테스트 통과. 기존 지도·열린 팝업·배경 타일·확대 위치가 별표 변경 후에도 유지되는 검증을 포함한다.
- 공개 빌드와 관리자 빌드 통과, 공개 파일 검사 통과: 192개 파일.
- 실제 로컬 지도 HTTP 200 및 수지구 7개 동 표시를 확인하고 변경 전/후 지도를 비교했다.
- 실제 풍덕천동 클릭, 별표 추가·해제, 지도 위치·팝업 유지, 저장 및 새로고침 복원, 즐겨찾기만 보기와 목록 제거를 확인했다.
- 모바일 390px·320px에서 가로 넘침이 없고 별표 사용이 가능했다. 데스크톱 및 모바일 지도를 시각적으로 확인했고 브라우저 오류는 없었다.
- 변경 차이의 공백 오류 검사 통과.

## 요약

동 경계의 선·색과 배경 대비를 높여 인접 구역을 더 쉽게 구분한다. 즐겨찾기는 금색으로 별도 강조한다. 구현·검증 완료 후 사용자의 후속 요청에 따라 변경 사항을 커밋·푸시 대상으로 포함한다.
