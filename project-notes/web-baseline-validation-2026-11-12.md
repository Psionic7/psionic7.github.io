# 새 아파트 기준본의 운영 웹 검증

검증일: 2026-11-12 KST. 최초 구현 커밋 `86cd409`를 main에 푸시하고 [Pages 배포 실행](https://github.com/Psionic7/psionic7.github.io/actions/runs/43042873502)의 성공을 확인했다. 실제 기기 대신 Playwright의 데스크톱 Chromium, 아이폰 WebKit 390×844, 안드로이드 Chromium 412×915 환경에서 점검했다.

## 운영 자료의 소유권과 버전

운영 웹의 `data/manifest.json`, `apartment-map/manifest.json`, `query-data/manifest.json`에서 기준본 세대 `2231257a459bd8c29b85b48f1faba05d0f4cf4fdbcd3989dac9e4ab49d511a2d`가 일치했다. 범위와 연결 해시도 로컬 패키지와 같았다.

운영 거래는 344,668건이다. 로컬 원본 344,537건보다 131건 많은 클라우드 자료가 유지됐다. 로컬 전체 DB로 수집 결과를 덮어쓰지 않고 로컬 아파트 기준만 설치한 결과다. 최초 배포의 기준본 검사·복원·원천 재대조·공개 내보내기·검사·배포가 모두 통과했다.

공개 Pages는 `/api/naver-listings/status`에 404를 반환한다. 기존 클라이언트가 로컬 수집 API의 유무를 확인한 뒤 정적 `/listings/snapshot.json`으로 전환하는 경로다. 이 HTTP 메시지와 실제 화면 오류를 구분했다. 로컬 경계 실패 시험의 HTTP 503은 의도적으로 주입한 값이다. 저장 후 렌더 예외는 관측하지 않았다.

## 점검에서 발견해 수정한 문제

### 경계 오류 안내가 지도 팝업 별표를 가림

기존 `.map-detail-status.error`는 지도 위에 절대 위치로 표시됐다. 모바일 팝업을 열면 안내의 재시도 버튼이 별표 위치에 겹쳐 Playwright의 정상 클릭도 `intercepts pointer events`로 실패했다. 배포 중 오래 열린 페이지의 경계 세대 불일치에서도 재현됐다.

로딩·오류 안내를 지도 캔버스 밖의 문서 흐름으로 옮겼다. 두 모바일 엔진에서 같은 경계 요청 실패를 주입한 뒤 별표를 클릭해 `즐겨찾기 저장됨`을 확인했다. 오류 주입을 해제하고 재시도하면 안내가 사라지고 저장도 유지됐다.

### 공유 제공자 ID의 서로 다른 관측 시점

최초 배포의 실제 자료는 라이프1차에 2026-11-08의 네이버 2623번 광고 127건, 라이프2차에 2026-11-11의 같은 번호 광고 131건을 가지고 있었다. 단지별 스냅샷만 선택하면 1차가 오래된 원문을 사용했다.

동결 기준본의 `shared_provider`와 유효한 활성 승인 관계로 명시된 대표·하위 범위만 같은 제공자 관측을 공유하도록 했다. 최신 `collectedAt`의 완전한 원문을 사용하고, 더 늦은 실패 시각·오류 상태는 각 대상에 별도로 보존한다. 같은 네이버 번호라는 이유만으로 연결 미승인 범위의 관측을 합치지 않는다. 제공자 번호가 바뀐 옛 DB 그룹도 현재 승인된 초기 관측을 가리지 않는다.

운영 웹의 실제 두 그룹을 메모리 DB에 재현한 결과, 둘 다 원문 131건과 같은 관측 시각을 사용했다. 웹 조회 함수의 동 범위 결과는 1차 63건·2차 68건이며 광고 ID 교집합은 0건이다. DB에 넣은 원래 127건·131건 스냅샷의 해시는 그대로였다. 결과는 Git 제외 경로 `local/apartment-baseline-validation/web-shared-provider-replay.json`에 있다.

### 별도 네이버 CI의 프로젝트 의존성 누락

별도 수집 검증 작업의 Ubuntu·Windows 실행이 `@turf/boolean-point-in-polygon` 모듈 누락으로 테스트 진입 전에 실패했다. 워크플로가 Python 의존성만 설치하고 프로젝트의 Node 의존성을 설치하지 않은 것이 원인이다. 메인 배포와 동일한 pnpm 11.25.0 및 잠금 파일 기반 설치 단계를 추가했다.

## 수정본 검사

화면 테스트 182개, 시스템 Chrome 단위 검사 19개, 일일 수집 검사 28개, 데이터 검사 46개가 통과했다. 공유 관측 검사에는 미승인 같은 번호 대상의 분리, 최신 원문 재사용, 늦은 실패 상태 보존, 원본 스냅샷 불변을 포함한다. 빌드의 전후 원본 DB 대조와 게시 검사도 통과했다.

브라우저 스냅샷·콘솔·스크린샷은 Git 제외 경로 `local/output/playwright/`에 있다. 로컬 미리보기는 `http://127.0.0.1:5173/`이다. 수정본의 원격 재배포와 라이프 63/68건 화면 확인 결과는 배포 완료 후 추가한다.
