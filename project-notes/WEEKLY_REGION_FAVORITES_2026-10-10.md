# 동 별 실거래가의 즐겨찾기 동 선택

## 분석

지역 지도에서 별표로 저장한 개인 동 목록은 App의 viewer.regions에서 복원하며, 기존 아파트별 조회에는 연결되어 있다. 동별 조회의 3번 조회할 동 필터는 catalog의 동 검색과 selectedIds를 사용하지만 개인 즐겨찾기 목록은 전달받지 않는다.

## 계획

1. App에서 기존 개인 지역 즐겨찾기를 WeeklyPage로 전달한다. 별도 저장소나 자동 조회 선택을 만들지 않는다.
2. 3번 조회할 동 필터의 상단에 즐겨찾기한 동을 표시한다. 검색 조건과 관계없이 저장한 동을 찾을 수 있고, 기존 체크박스와 같은 선택 상태를 사용한다.
3. 복수 선택·해제, 검색 목록과 동기화, 전체 해제, URL 및 브라우저 선택 복원, 지역 지도 즐겨찾기 변경과 미수집 동을 검증한다.
4. 테스트 및 빌드 후 모바일과 실제 로컬 화면을 확인하고 결과를 기록한다.

## 구현 결과

- 3번 조회할 동 필터 상단에 개인 즐겨찾기 동 목록과 개수를 추가했다. 저장한 순서대로 동 이름과 시·군·구를 표시하고, 미수집 지역에는 미수집 안내를 표시한다.
- 즐겨찾기 목록은 검색 조건과 관계없이 표시된다. 기존 검색 목록과 같은 selectedIds 및 toggle을 사용해 두 목록의 체크 상태가 동기화된다.
- 여러 동 선택, 개별 선택 해제, 선택 모두 해제, 조회 결과 제거, URL과 브라우저 저장·복원을 기존 동작으로 처리한다. 조회 선택을 변경해도 지역 지도에 저장한 즐겨찾기 목록은 유지된다.
- 지역 지도에서 즐겨찾기를 변경한 뒤 동별 탭으로 돌아오면 목록이 반영된다. 이미 선택해 조회 중인 동은 즐겨찾기를 해제해도 조회 선택을 유지한다.
- 개인 즐겨찾기가 비어 있으면 지역 지도의 별표로 추가하도록 안내한다. 관리자 수집 대상 목록을 개인 즐겨찾기로 가져오지 않는다.
- 기존 체크박스 디자인과 모바일 한 열 배치를 재사용했다.

## 검증 결과

- React 테스트 12개 파일, 69개 테스트 통과. 추가 검증은 즐겨찾기와 검색 선택 동기화, 검색 조건과 별도 선택, 같은 동 이름의 지역 구분, 복수 선택, 전체 해제, 선택 복원, 미수집 동, 알 수 없는 ID 제외, 지역 지도 변경 반영을 포함한다.
- 공개 빌드 통과, 공개 파일 검사 통과: 183개 파일.
- 독립 브라우저 프로필에서 저장된 지역 즐겨찾기 목록 표시, 풍덕천동 선택과 URL 반영, 검색 체크박스 동기화, 접기·펼치기 유지, 새로고침 복원, 선택 모두 해제 후 즐겨찾기 유지 및 HTTP 200을 확인했다.
- 모바일 390px·320px에서 가로 넘침 없이 동 선택·해제가 가능하며, 390px 화면을 시각적으로 확인했다. 브라우저 스크립트 오류는 없었다.
- 변경 차이의 공백 오류 검사를 통과했다.

## 요약

지역 지도에서 즐겨찾기한 동을 동별 실거래가의 3번 조회할 동 필터에서도 바로 선택할 수 있다. 기존 검색 목록 및 조회 결과와 같은 선택 상태를 사용한다. 구현·검증 후 사용자의 후속 요청에 따라 변경 사항을 커밋·푸시 대상으로 포함한다.
