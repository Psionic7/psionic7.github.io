# 실거래가 패널 접기 · 2026-10-10

## 분석
조회 필터 안의 번호별 그룹에는 접기 기능이 있었으나 필터 전체 패널과 각 동·아파트 결과 패널에는 없었다. 직전 요청으로 제거한 결과 패널의 제거 버튼은 다시 추가하지 않는다.

## 계획
두 위치에서 공통 CollapsiblePanel을 사용한다. 버튼은 배지 등 다른 요소보다 오른쪽에 배치한다. 내용은 hidden으로 숨겨 필터 조건, 내부 그룹의 펼침 상태, 조회 선택과 거래 페이지를 유지한다. 새로고침 뒤에는 기본 펼침 상태로 시작한다.

## 구현
- 필터 전체와 동·아파트 결과 패널에 독립적인 접기·펼치기 버튼을 추가했다.
- 제목, 주소·조회 기간과 선택 개수는 접어도 표시한다.
- button의 aria-expanded·aria-controls와 useId를 사용하며 키보드 조작을 지원한다.
- 공통 패널 내부 래퍼에 맞춰 필터 그룹 간격을 조정했다.

## 검증 결과
- 동별·아파트별 조회와 설정 저장 회귀 테스트 3개 파일, 27개 테스트 통과. 독립 접기, 조건·검색·중첩 그룹 상태·거래 페이지 보존, 추가 자료 요청 없음과 Enter 키 동작을 검증했다.
- 공개 빌드, 게시 파일 검사(205개)와 git diff --check 통과.
- 실제 브라우저에서 동별·아파트별 각각 1360px·390px·320px 화면의 HTTP 200, 우측 끝 버튼 배치, 배지가 버튼 왼쪽에 위치함, 독립 접기, 조건 보존과 Space 키 재펼침을 확인했다. 가로 넘침과 JavaScript 오류가 없었다.
- 390px 모바일 캡처로 실제 접힌 필터·결과와 나머지 펼친 결과가 함께 정상 표시되는지 확인했다.

## 요약
각 결과 패널과 필터 전체를 접어 화면을 줄일 수 있다. 작업은 직전 제거 버튼 변경을 포함한다. 후속 요청에서 사용자가 현재 변경의 커밋·푸시를 명시적으로 요청하여 소스·테스트·빌드 결과·작업 기록을 함께 main에 반영한다.
