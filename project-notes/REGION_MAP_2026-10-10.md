# 지역 지도와 개인 지역 즐겨찾기

## 분석

관리자 지도는 admin/RegionMap.jsx에서 동 경계와 시·군·구 경계를 함께 표시한다. src/CloudRegionMap.jsx는 같은 정적 경계 파일을 읽고 공통 지도에 전달한다. 기존 공개 조회의 즐겨찾기 지역 목록은 관리자 수집 지역 manifest를 읽고 있으며, 개인 아파트 즐겨찾기는 home-records.preferences.v1의 viewer.apartments에 저장한다.

## 계획

1. 관리자 지도 컴포넌트를 재사용하고 기본 관리자 동작은 유지한다. 공개 지도에서는 별표/팝업/범례를 개인 지역 즐겨찾기 기준으로 표시한다.
2. 아파트 지도 바로 오른쪽에 지역 지도 탭을 추가하고 URL/탭 복원을 지원한다.
3. 개인 동 ID를 같은 브라우저 저장소의 viewer.regions에 저장한다. 아파트 즐겨찾기와 관리자 수집 설정은 각각 유지한다.
4. 지역 지도에 시도·시군·구 필터, 동 이름 검색, 즐겨찾기만 보기와 저장된 지역 목록을 제공한다. 기존 아파트별 조회의 즐겨찾기 지역 목록도 개인 목록을 사용한다.
5. 관리자 기본 동작, 별표 후 지도/팝업 유지, 재접속 저장, 아파트와 지역 저장 분리, 잘못된 저장값 및 모바일 화면을 검증하고 결과를 추가한다.

## 구현 결과

- 아파트 지도 오른쪽에 지역 지도 탭을 추가했다. `?tab=regions`로 직접 열고 마지막 탭을 복원할 수 있다.
- 관리자와 같은 공통 지도 컴포넌트, 서울·경기 1,212개 법정동 경계, 시·군·구 경계 및 색상을 재사용한다.
- 공개 지도 팝업의 별표는 개인 지역 즐겨찾기를 추가·해제한다. 관리자 수집 설정은 변경하지 않는다.
- 아파트 즐겨찾기와 같은 `home-records.preferences.v1` 브라우저 저장 문서의 `viewer.regions`에 동 ID를 저장한다. 기존 `viewer.apartments`와 각각 저장·복원한다.
- 시도·시군·구 및 이름 필터, 즐겨찾기만 보기, 저장된 지역 목록을 제공한다. 아파트별 실거래가의 즐겨찾기 지역 목록에도 연결했다.
- 별표 변경 시 기존 지도·타일·팝업을 재생성하지 않고 선택 스타일만 갱신한다. 즐겨찾기만 보기에서는 표시할 지역이 바뀌므로 지도 표시 범위를 갱신한다.

## 검증 결과

- React 테스트: 12개 파일, 66개 테스트 통과. 관리자 기본 동작, 개인 즐겨찾기 저장·복원, 아파트 저장값 유지, 탭 순서, 조회 화면 연결, 잘못된 저장값, 별표 변경 시 지도 유지 등을 검사했다.
- 공개 빌드 및 관리자 빌드 통과.
- 공개 파일 검사 통과: 182개 파일.
- 실제 브라우저에서 로컬 페이지 HTTP 200, 아파트 지도 다음 탭 배치, 풍덕천동 경계 클릭, 팝업 별표 저장·해제, 새로고침 복원, 아파트 조회 화면 즐겨찾기 연결을 확인했다.
- 실제 별표 클릭 전후 지도 요소·팝업·캔버스와 지도 위치가 유지됨을 확인했다. 즐겨찾기만 보기와 하단 목록의 해제도 확인했다.
- 모바일 폭 390px·320px에서 가로 넘침이 없고 390px에서 별표 추가·해제가 동작했다. 브라우저 스크립트 오류는 없었다.
- 변경 차이의 공백 오류 검사를 통과했다.

## 요약

관리자와 같은 지역 경계 지도를 공개 화면에서 사용할 수 있다. 지도 별표로 저장한 개인 지역은 아파트 즐겨찾기와 같은 브라우저 저장소에 보존하며 아파트 조회 조건에서도 선택할 수 있다. 사용자 요청에 따라 커밋·푸시 대상으로 포함한다.
