## 범위와 한계

실제 사용자 즐겨찾기·수집 DB·인증키는 변경하지 않았다. 외부 API 유료 호출이나 운영 수집·배포는 실행하지 않았다. B09의 관리자 API 실행은 임시 DB와 주입한 빌드 프로세스로 검증했으며, 같은 공통 진입점의 실제 빌드는 CLI에서 실행했다.

동별 ‘미수집’ 표시는 기존 앱의 자료 제공 판정에 맞춘 것이다. 원천에서 거래가 없었던 동과 수집하지 않은 동을 더 정밀하게 구분하려면 수집 완료 메타데이터를 별도로 확장해야 한다. 이미 시작한 정상 조회의 다운로드 취소는 이번 수정 범위에 포함하지 않았다. 잘못된 날짜가 새 전체 기간 조회를 시작하는 경로를 차단했다.

Web Locks 미지원 브라우저는 최신 저장값 읽기와 변경 이벤트 동기화를 사용한다. 완전히 같은 순간의 쓰기를 직렬화하는 보장은 Web Locks 지원 환경에 한한다. 브라우저 검증은 해당 API를 지원하는 Chromium에서 수행했다.
