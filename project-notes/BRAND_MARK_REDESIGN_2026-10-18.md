# 메인 아이콘 교체 · 2026-10-18

## 분석
기존 로고는 짙은 남색 배경에 집·문·가로선 윤곽이 겹쳤다. 사이트는 #2858DF 파란색을 포인트로 사용하지만 로고 바탕은 별도 남색이어서 색이 달랐다. 메인 로고와 favicon은 서로 다른 SVG 코드였고 로컬 관리자는 또 다른 집 아이콘을 사용했다.

## 계획
사이트의 포인트 색상에 맞춘 새 벡터 아이콘을 만들고 메인 로고·브라우저 탭·관리자 아이콘에서 하나의 SVG 원본을 공유한다. 작게 표시할 때도 알아볼 수 있게 복잡한 윤곽선 대신 면과 두 줄의 기록 선을 사용한다.

## 구현 결과
- 파란색 타일 위에 흰 집 모양의 기록 카드와 반투명 뒷장을 조합한 새 SVG를 작성했다.
- src/brand-mark.svg를 원본으로 사용하고 BrandMark 컴포넌트는 해당 자산을 표시한다. 공개·웹 관리자·로컬 관리자의 탭 아이콘에도 같은 원본을 사용한다.
- 기존 favicon.svg를 제거했다. Vite의 콘텐츠 해시 경로로 빌드되어 새 아이콘이 이전 탭 아이콘 캐시와 구분된다.
- 기존 남색 배경과 그림자를 제거하고 아이콘이 화면별 42px·38px·36px 크기를 채우게 했다.
- 로고 링크의 텍스트와 이동 동작은 유지하고 장식용 이미지의 중복 읽기를 숨겼다.

## 검증 결과
- 기존 공개 UI 및 로컬 관리자 테스트 2개 파일, 17개 테스트 통과. 단순 아이콘 교체를 위한 별도 테스트는 추가하지 않았다.
- 공개 사이트 빌드·로컬 관리자 빌드·공개 파일 검사(999개)와 git diff --check 통과.
- 실제 브라우저 1440px·390px·320px에서 SVG 로드, 아이콘과 컨테이너의 크기 일치, 포인트 색상 일치, 가로 넘침 없음과 JavaScript 오류 없음을 확인했다.
- 공개 페이지의 로고와 탭 아이콘이 같은 해시 SVG를 사용하고 웹 관리자 아이콘도 HTTP 200으로 제공됨을 확인했다. 로컬 관리자 빌드에도 같은 SVG가 포함됐다.
- 데스크톱 로고 확대 캡처와 모바일 화면을 직접 확인했다.

## 요약
메인 아이콘을 파란색의 집·기록 카드 형태로 새로 교체했다. 로고와 탭 아이콘의 원본을 통일했으며 후속 요청에서 사용자가 현재 변경의 커밋·푸시를 명시적으로 요청하여 소스·정적 화면 빌드·작업 기록을 함께 main에 반영한다.

빌드에서 복사한 docs/query-data의 월별 조회 자료 761개(약 103MB)는 원본 public/query-data와 동일한 자동 생성 산출물이다. GitHub Actions의 pnpm build 단계가 배포 전에 다시 생성하므로 해당 폴더도 Git에서 제외한다. 로컬 미리보기 파일은 유지하며 기존 원본 데이터·수집 설정·워크플로는 변경하지 않는다.
