# 집 찾기 화면 복원 수정 — 2026-10-18

## 원인과 변경

주요 메뉴의 집 찾기 버튼이 항상 `setTab('apartments')`를 호출하여, 동네 거래·단지 지도·동네 지도를 보다가 다른 메뉴를 거쳐 돌아오면 단지 거래로 바뀌었다.

`explorer.lastExploreTab`에 마지막 집 찾기 하위 화면을 저장하고 복귀 시 사용하도록 수정했다. 이미 집 찾기에 있을 때 같은 메뉴를 눌러도 현재 하위 화면을 유지한다. 주소로 직접 연 화면이 저장된 다른 하위 화면보다 우선하며, 저장값이 없거나 잘못된 경우 단지 거래를 기본값으로 사용한다. 새로고침이나 재방문 후에도 마지막 하위 화면을 복원한다.

기존 동/단지 선택과 조회 기간·면적 조건의 저장 형식은 유지한다. 관심 목록에서 명시적으로 실거래 검색이나 특정 단지/동을 여는 버튼은 해당 조회 화면으로 이동한다.
