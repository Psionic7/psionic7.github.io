# 새 즐겨찾기 대시보드

## 분석

개인 동 즐겨찾기는 viewer.regions, 아파트는 viewer.apartments에 저장되어 있고 조회 화면은 공통 거래표를 사용한다. 이전 대시보드는 아파트 조회로 통합되었다. 새로운 대시보드는 선택 필터/거래표를 반복하는 대신 관심 동·아파트의 활동 요약, 최근 계약과 상세 조회 연결에 집중할 수 있다. 서로 겹치는 관심 동/아파트와 공식 단지 거래 별칭은 중복 집계에 주의해야 하며 미수집·실패를 0건으로 보이면 안 된다.

## 계획

1. 가장 왼쪽에 새 대시보드 탭을 추가하고 새 방문의 기본 탭으로 사용한다. 기존 유효한 마지막 탭은 복원한다.
2. 자료 기준일의 최근 7/30/90일을 선택하고 개인 즐겨찾기 동·아파트의 거래 건수와 마지막 유효 계약을 요약한다.
3. 관심 거래 흐름, 동별 활동과 이전 같은 길이 기간의 건수 차이, 아파트별 마지막 계약의 가격·전용평·층, 최근 관심 거래를 제공한다. 동·아파트가 겹치는 신고는 최근 목록/합계/흐름에서 한 번만 집계한다.
4. 미수집·로딩·실패·빈 자료와 비교 기간 미확보를 구분한다. 좋아 보이는 가격 변동을 임의 추정하지 않고 마지막 계약의 면적을 함께 표시한다.
5. 각 동/아파트를 누르면 동일 기간의 기존 조회 탭으로 연결한다. 즐겨찾기 자체는 변경하지 않으며 대시보드에 들어가기만 해도 기존 조회 선택/필터가 바뀌지 않게 한다.
6. 필요한 시군구만 기존 캐시로 읽고, 계산 모델·집계/복원·탭 연결·부분 실패 및 실제 모바일 화면을 검증한다. 문서와 게시 빌드를 갱신한 뒤 사용자가 요청한 커밋·푸시까지 수행한다.

현재 상태: 구현 및 검증 완료. 이번 요청에 명시된 커밋·푸시를 진행한다.

## 구현 결과

- 새 대시보드를 첫 탭 및 새 방문 기본 탭으로 추가했다. 유효한 기존 마지막 탭은 유지한다.
- 대시보드, 표시 위젯, 순수 집계 모델, 스타일을 기능별로 분리했다. 새로운 차트 의존성을 추가하지 않았고 HTML 막대와 펼쳐 볼 수 있는 수치 표를 사용했다.
- 즐겨찾기 시군구만 읽고 동/단지 인덱스로 조회한다. 같은 시군구의 동과 아파트는 요청을 공유하고 7/30/90일 변경은 다시 다운로드하지 않는다.
- 최근 거래·흐름은 시군구 코드와 신고 ID로 중복을 제거한다. 공식 단지 거래 별칭과 동일 이름의 다른 지번을 구분한다. 카드의 마지막 계약은 전체 수집 자료 기준임을 표시한다.
- 대시보드 진입만으로 기존 조회 선택과 필터를 변경하지 않는다. 상세 조회 버튼을 누르면 같은 기간으로 연결하고 면적 필터를 초기화해 대시보드와 다른 결과가 나오지 않게 했다. 최근 해제 거래 연결 시 해제 거래 포함을 활성화한다. 즐겨찾기는 그대로 유지한다.
- 수집 자료가 없거나 실패한 곳은 0건 대신 상태를 표시한다. 일부 월의 자료가 없으면 부분 자료를 알리고 이전 기간 비교를 숨긴다. 실패한 시군구만 다시 불러올 수 있다.

## 검증 결과

- React 통합 테스트: 14개 파일, 84개 테스트 통과. 기존 지도·거래 조회·저장 설정·즐겨찾기 테스트를 포함한다.
- 순수 집계 모델 테스트: 8개 통과. 경계일·해제·미래 계약·단지 별칭·중복·부분 수집·윤년·기간 복원을 검사했다.
- 공개 빌드 및 게시 파일 검사: 통과, 201개 파일 검증.
- 실제 로컬 게시 빌드의 Playwright 확인: 1440px 데스크톱 및 390px·320px 모바일에서 페이지 가로 넘침과 JavaScript 오류가 없었다. 스크린샷으로 카드와 표를 확인했다.
- 실제 수지구 121,457개 행을 사용했다. 풍덕천동·동천동 및 보원·동보·현대 예시의 30일 기간(2026-09-04~2026-10-03)은 동 65건, 아파트 6건으로 일치했다. 90일 중복 제외 집계는 354건이었다. 미수집 청운동을 0건과 구분했다.
- 동·아파트가 같은 시군구일 때 요청 1회, 기간 변경 및 상세 조회 이동 중 추가 요청 없음, 즐겨찾기 보존, 기간 공유·새로고침 복원을 확인했다.
- 검증용 브라우저와 예시는 별도 세션에서 사용했다. 기존 사용자의 브라우저 즐겨찾기를 수정하지 않았다.

## 요약

대시보드에서 개인 관심 지역의 거래 활동과 마지막 계약을 한눈에 보고 기존 조회 화면으로 이어 갈 수 있다. 선택 기간은 실제 자료 기준일을 따른다. 단지마다 면적과 거래 조건이 달라 임의의 가격 상승률·수익률을 산출하지 않았다. 분석·계획·결과는 이 문서에, 사용 방법은 README에 남겼다.
