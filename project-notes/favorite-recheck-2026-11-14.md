# 즐겨찾기 재점검

점검일: 2026-11-14. 점검 시작 시 커밋은 `527ebed`다.

## 운영 반영 확인

[배포 실행 43580956265](https://github.com/Psionic7/psionic7.github.io/actions/runs/43580956265)의 준비·배포 단계가 모두 성공했다. 운영 HTML이 참조하는 실제 JavaScript 번들에도 즐겨찾기 전체 보기와 다중 선택 안내가 포함돼 있었다. 이는 게시 확인이며 실제 iPhone·Android 기기 조작 검증은 아니다.

## 추가로 재현한 문제와 수정

브라우저 저장 공간이 부족하거나 저장이 차단됐을 때, `useStoredState`가 저장 전에 즐겨찾기 상태를 바꿨다. 저장 요청은 실패했지만 별표는 선택된 상태여서, 사용자가 다시 누르면 저장 재시도가 아니라 해제로 처리됐다. 해제 실패 때도 화면만 먼저 해제돼 새로 열면 다시 저장된 것으로 보였다.

`viewer` 범위의 즐겨찾기는 브라우저 저장이 성공한 뒤 화면 상태를 확정하도록 수정했다. 실패하면 이전 별표·목록 상태와 실패 안내를 유지하며 같은 동작을 다시 시도할 수 있다. 면적·기간 등 다른 조회 설정의 저장 실패 시 화면과 공유 URL에 현재 설정을 유지하는 기존 동작은 보존했다.

저장 실패 후 별표가 잘못 선택되는 App 테스트와 해제 실패 후 목록이 먼저 비워지는 저장 훅 테스트가 수정 전 실패하고 수정 후 통과했다. 재시도 성공 후 실제 저장값도 확인했다.

## 검증 한계

실제 iPhone Safari와 Android Chrome 기기는 연결되지 않았다. 로컬 서버의 정상 응답과 최신 저장 모듈 제공은 확인했으며 Codex 브라우저 패널 열기를 요청했지만 대기 상태였다. 따라서 기기별 화면·터치·브라우저 저장 정책 전체에서 오류가 없다고 단정하지 않는다. 이번 추가 수정의 커밋·푸시는 별도 요청 전에는 수행하지 않는다.
