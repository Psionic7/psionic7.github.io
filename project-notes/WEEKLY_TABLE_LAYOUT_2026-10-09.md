# 동별 실거래 목록 모바일 표시 수정 (2026-10-09)

기존 목록은 아파트 이름과 주소를 한 셀에 표시하고 거래유형 컬럼을 포함했다. 주소가 이름 셀의 폭을 늘려 모바일에서 중요한 거래 정보를 확인하기 어려웠다.

수정 순서: 계약일 → 아파트 이름 → 전용면적(평) → 층 → 거래금액 → 거래 상태/해제일 → 주소. 주소는 독립된 마지막 셀로 분리하고 거래유형 컬럼은 제거했다. 초기 변경에서는 즐겨찾기 버튼을 유지했으나, 아래 후속 요청으로 목록에서 제거했다.

계약일은 YYYY-MM-DD 원문에서 YY.MM.DD로 표시한다. time 요소의 datetime과 title에는 원래 날짜를 유지하며 기간 필터와 날짜 정렬에는 원문을 사용한다. 해제일은 기존 형식을 유지한다.

동별 목록의 전용면적은 평으로 환산하며, 필터의 ㎡/평 단위 선택은 그대로 사용할 수 있다. 같은 컴포넌트를 사용하는 대시보드 즐겨찾기 목록은 기존의 선택 단위를 따른다.

변경: src/weekly/WeeklyResults.jsx 및 docs/ 공개 빌드 파일. 데이터 원문은 변경하지 않았다.

검증: React 61개 테스트, pnpm build, pnpm check:publish(166개 파일), git diff --check 통과. 실제 브라우저에서 7개 컬럼 순서, 짧은 날짜, 날짜 원문 보존, 전용평, 주소 분리를 확인했다. 모바일 390px에서 문서 넘침 없이 표 내부로 가로 스크롤되며 왼쪽의 계약일/아파트 이름과 오른쪽의 주소를 확인했다. pageerror 0개. 로그와 화면은 비공개 local/weekly-columns-* 파일에 저장했다.

## 후속 요청: 버튼·중복 금액 제거 및 행 높이 축소

거래 목록의 행별 즐겨찾기 버튼과 그 전달 콜백을 제거했다. 지도와 아파트 상세의 즐겨찾기는 기존대로 사용할 수 있으며 저장된 즐겨찾기도 유지한다. 거래금액은 억 원만 표시하고 아래 만 원 금액은 제거했다.

표 헤더/셀의 위아래 여백은 3px, 좌우 여백은 8px, 줄 높이는 1.3으로 조정했다. 거래 상태 배지 여백도 줄이고 해제일을 배지 옆에 한 줄로 표시한다. 글자 크기와 컬럼 순서는 유지하며 다른 표에는 이 여백을 적용하지 않는다.

수정 파일: src/weekly/WeeklyResults.jsx, src/WeeklyPage.jsx, src/App.jsx, src/styles.css, tests/favorites.test.jsx 및 docs/ 공개 빌드. 버튼으로 추가하던 이전 테스트는 목록에 버튼이 없고 기존 즐겨찾기가 요청 실패/빈 조회에서 보존되는 흐름으로 갱신했다.

최종 검증: React 테스트 61개, 공개 빌드, 공개 파일 검사(170개), git diff --check 통과. 실제 2026년 9월 풍덕천동 47개 행에서 높이가 61px에서 22px로 감소했으며 데스크톱과 모바일 390px에서 동일했다. 행 버튼 없음, 만 원 표시 없음, 억 원 표시, 컬럼 순서와 모바일 문서 폭 유지, pageerror 0개를 확인했다. 결과는 local/weekly-compact-browser-result.json, 전후 높이는 local/weekly-compact-before.json, 화면은 local/weekly-compact-desktop.png 및 local/weekly-compact-mobile.png에 저장했다. 커밋·푸시는 하지 않았다.

## 후속 요청: 주소 컬럼 제거

거래 목록의 주소 헤더와 행별 주소 셀을 제거했다. 현재 컬럼은 계약일, 아파트 이름, 전용면적(평), 층, 거래금액, 거래 상태/해제일의 6개다. 단지 카드 제목에 사용되는 주소와 데이터 원문은 유지한다.

## 후속 요청: 면적 소수점 한 자리

공급면적(전용면적) 표시 요청을 검토했으나 현재 수집·저장된 거래 면적은 전용면적뿐이다. 사용자에게 확인한 결과, 공급면적 자료 확보 전까지 전용면적만 표시하기로 했다. 공급면적을 임의 환산하거나 전용면적을 공급면적으로 바꾸어 표기하지 않는다.

현재 목록은 전용면적을 소수점 한 자리로 표시한다(25.56평 → 25.6평). 원본 면적과 필터 계산은 그대로 유지한다. 표시 자릿수 변경에 맞춰 기존 주간 테스트 기대값을 갱신했다.

검증: 관련 테스트 16개, 공개 빌드, 공개 파일 검사(170개), git diff --check 통과. 실제 브라우저에서 25.6평 표시, 6개 컬럼, 데스크톱/모바일 행 높이 22px, 모바일 문서 폭 390px, pageerror 0개를 확인했다. 커밋·푸시는 하지 않았다.
